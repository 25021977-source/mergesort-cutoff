# Thực nghiệm CUTOFF trong Mergesort

## Mục tiêu
Tìm ngưỡng CUTOFF phù hợp với chương trình Java và máy tính dùng để chạy
thí nghiệm. CUTOFF là số phần tử tối đa của một đoạn mảng mà chương trình
sẽ sắp xếp bằng insertion sort thay vì tiếp tục chia đôi.

## Cách thực hiện
- Cài đặt mergesort và insertion sort theo bài giảng.
- Thử nhiều giá trị CUTOFF, trong đó có 7 và 10.
- Với mỗi ngưỡng, sắp xếp bản sao của cùng một mảng và đo thời gian nhiều lần.
- Kiểm tra kết quả sắp xếp, lập bảng thời gian và vẽ đồ thị để so sánh.
